## Other packages

| Package | One line |
| --- | --- |
| `@pyreon/validation` | Home of the validation contract (`ValidationError`, `ValidateFn`, `SchemaValidateFn`) and the Standard Schema bridge (`isStandardSchema`, `standardSchemaToValidator`, `wrapStandardSchema`, `InferSchema`), plus Zod/Valibot/ArkType adapters. No Pyreon deps. The Standard Schema TYPE is `StandardSchemaV1` from the types-only `@standard-schema/spec` (re-exported here); no @pyreon package declares its own copy — `@pyreon/http`, `@pyreon/zero` and `@pyreon/zero-content` depend on the spec package directly because they do not (or only optionally) depend on validation. `isStandardSchema` accepts callable schemas (ArkType schemas are functions carrying `~standard`). Discriminate a Standard Schema result on `issues`, never on `'value' in r` — valibot's failure result carries both. `@pyreon/form`'s `resolveSchemaValidator` checks `isStandardSchema` BEFORE its `typeof === 'function'` → `SchemaValidateFn` fallback, so a raw ArkType schema in `useForm({ schema })` is treated as a schema. |
| `@pyreon/http` | HTTP client under `@pyreon/query`: onion middleware, immutable clients (`extend()`), typed errors (`AbortError` distinct), timeout on by default. `.json<T>()` cast · `.json(parseFn)` · `.json(schema)` via `@pyreon/http/schema`. `endpoint('GET /users/:id')` derives call, cache key and response type from one declaration. `:name` placeholders are read in the PATH part only (after `scheme://authority`, before the first `?` / `#`: `pathPartStart` / `pathPartEnd` in `url.ts`); `applyPathParams`, the type-level `PathParamNames`, the native plugin's resolver and `@pyreon/feature` (item URL, native crud refusal) must keep cutting at the same point, and `\\:` still reads as a colon outside it. Native base joining uses the web's `joinPrefix` (= `joinUrl`), never a concatenation. Subpaths `/middleware`, `/schema`, `/query`, `/mock`, `/server` (the only `node:async_hooks` import), `/json` and `/stream`. Streams own reader cancellation and abortable connect/parse waits; detach external signals even before iteration, cancel late bodies, and emit `closed` once. SSE commits IDs at blank lines (empty clears the resume header), applies retry fields immediately, resets retry budgets on filtered valid events, and treats no-body/204 as terminal even with `onEnd`. Scan each decoded chunk once and join a completed line once. |
| `@pyreon/i18n` | `createI18n({ locale, messages, loader?, fallbackLocale?, … })`; `t(key, values?)` with `{{name}}` interpolation, format specifiers (`{{amount, currency}}`), plurals (`_one`/`_other`/`_zero`), `context`, `defaultValue`, `$t(key)` nesting (depth 4). Formatters `n`/`d`/`rt` read `locale()` reactively. Entries `@pyreon/i18n` (with `Trans`, `I18nProvider value={i18n}`, `useI18n`; `<Trans i18nKey>` reads `t` from context) and the framework-agnostic `@pyreon/i18n/core`. Opt-in typed keys via `createI18n<typeof en>()` (`MessageKeys<M>`, `TranslationParams`). `t()` renders from a compiled cache, one entry per (active locale, key as passed, plural/context variant), with `{{…}}` pre-split. Any message mutation (`addMessages`, a resolved `loadNamespace`) must call `invalidateResolutions()`. Bounds: 8 locales × 2 generations × 1,000 keys × 32 variants per key. Intl formatters are bounded per locale. `onMissingKey` and `defaultValue` are never cached. |
| `@pyreon/feature` | Schema-driven CRUD (queries, forms, tables, stores). Validation accepts Zod or any Standard Schema; field introspection (`extractFields`: auto form fields, columns, create defaults) is Zod-only — other schemas need explicit `initialValues` (dev-warned once). |
| `@pyreon/virtual` | TanStack Virtual adapter. |
| `@pyreon/charts` | Pyreon's own charting engine: `<Chart>` with mark children, twenty family components, `/svg` (SSR), `/engine` (everything, unstable); theme tokens via `ChartThemeProvider`, `chartThemes`, `palettes`; draws natively on iOS/Android. Band edges share a gap mask and pair runs by index, including singletons; resolve both channels once per frame. Keyed geometry uses `isFiniteNumber`, including on transformed values. Bench: `bench:engine`. |
| `@pyreon/hooks` | 65 signal-based hooks. `useFocusTrap` places `initialFocus` one microtask after activation; with focus already in the container, `true` never moves it and a named target moves it only on first activation or when the activation ran in a user event at the focused element (`activatedByFocusedElement`, reads `window.event`) — a toggle inside the trapped header works on every open (#4355), a trap re-arming after `saving()` never steals the field; locked by `useFocusTrap.browser.test.ts`. |
| `@pyreon/hotkeys` | Keyboard shortcuts: key-bucketed dispatch, refcounted scopes, `mod` alias, sequences (`g t`), comma lists, keyup bindings, `once`/`ignoreRepeat`, element targets, `trigger()`, conflict detection, SSR-safe. |
| `@pyreon/document` | Document rendering: 18 primitives, 20 output formats. |
| `@pyreon/url-state` | `useUrlState` with schema mode and type coercion; SSR-safe. |
| `@pyreon/dnd` | Wraps `@atlaskit/pragmatic-drag-and-drop`; every teardown goes through `onCleanup`, and `useSortable` disposes item and container registrations on ref `null`. |
| `@pyreon/a11y` | `announce()`, `<VisuallyHidden>`, `<LiveRegion>`, `<SkipLink>`, `createA11yId`. |
| `@pyreon/format` | Experimental. Plain functions over `Intl` (`formatNumber`, `formatCurrency`, `formatBytes`, `formatDuration`, `formatDate`, `formatRelativeTo`, ...), `parseNumber`, `parseDate`, `defineFormats`, `createFormatter`. Entries `/core` (pure), `@pyreon/format` (reactive: `locale`/`setLocale`/`provideLocale`, `timeZone`/`setTimeZone`/`provideTimeZone` are RE-EXPORTED from `@pyreon/ambient`, which owns locale, zone and clock for format, time and i18n; `useRelativeTime`) and `/components` (`<Num>`, `<DateTime>`, `<RelativeTime>`). Date-only and offset-less strings are CALENDAR values: formatted as UTC, never shifted by the zone (the `PLAIN` variant in `datetime.ts`); in RELATIVE time a date-only target is that day's midnight in the display zone (`zoneMidnight`), the rule `@pyreon/time`'s `relativeDistance` uses, with one shared case table tested in both. Unit conversion lives in its own entries `@pyreon/format/units` (active locale) and `/units/core` (pure): `convert.ts` holds an exact-rational table built lazily and applied as ONE combined factor, `unit-convert.ts` the converting formatter kind; nothing in `core.ts`, `index.ts` or `components.ts` may import them (a test greps the minified bundles for `mile-scandinavian`). `useRelativeTime` schedules each label at its own next change through `useNow({ every: () => ({ at }) })` (one shared timer for all labels, one for seconds); `nextRelativeChange` in `datetime.ts` must stay consistent with `relativeFrom`. Cache: three tiers (no options, preset string, options object by identity then structural key), every table bounded (`cache.ts`); table builders are `/* @__PURE__ */` so one function tree-shakes. Dev-only warnings are gated at the CALL SITE with the bare `process.env.NODE_ENV !== 'production'` check so production bundles drop the message text. `setLocale` is a no-op on the server: use `provideLocale` (request-scoped context). Never throws on data (fallback plus one dev warning); bad options, units and presets throw `[Pyreon]` errors. Manifest examples are re-evaluated by `manifest-examples.test.ts`. |

Chart animation state separates the latest target from the displayed frame.
Retarget values from `frameCache` and keyed positions from `geoSnap`, including
visible entering/exiting bars. A running universal transition owns its draw
list; feed it new targets without starting a concurrent value tween. Cancelling
updates must release either animation's pending frame.
