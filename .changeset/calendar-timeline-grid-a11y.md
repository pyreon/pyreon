`<TimelineView>` is a proper WAI-ARIA grid. Each resource row has one gridcell per shown day under the day headers (a bar sits in the cell of the day it starts on), every row carries `aria-rowindex` (windowed rows too), and the grid has one tab stop with a roving tabindex: arrows by day and resource, Home/End, Ctrl+Home/End, PageUp/PageDown, Enter into a day's events (or selecting the day when it has none), Escape back. In a windowed list the tab stop moves to the nearest drawn row when its own row is scrolled away, and a focused row that scrolls out hands the focus to that cell instead of dropping it to the page. Up to 100 resources every row is drawn so a screen reader's reading cursor reaches them all; the new `windowed` prop (`true`, `false` or a threshold, also on `<Calendar>`) changes that. `businessHours` now mark the timeline as they shade the time grid (`data-business` on the cells, open hours drawn light), and the empty state is a row of the grid instead of a bare `<p>`. Fixes #4848.
