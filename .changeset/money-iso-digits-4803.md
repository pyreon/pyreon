'@pyreon/money': minor
---

Currencies are now ISO 4217 list one (178 codes as amended on 2026-09-17, shipped with the package) on every engine, with ISO 4217 minor units. Both used to come from `Intl`, which disagrees between engines: V8 (Node, Chrome) reports CLDR display digits (0 for HUF, IDR, COP, PKR, IQD and others) and lists 162 codes, JavaScriptCore (Bun, Safari) reports ISO 4217 digits and lists 307 codes including withdrawn ones, so a Money made on the server could be invalid in the browser. Breaking: on V8, `currencyDigits('HUF')` is now 2 (was 0) and `IQD` 3 (was 0), so a stored HUF amount such as `"100"` must become `"100.00"`. On JavaScriptCore, withdrawn codes such as `HRK` are no longer accepted; register them with `defineCurrency`. `defineCurrency` can now give an ISO currency the digits a payment provider uses (`defineCurrency('ISK', { digits: 2 })`); a code is still defined once, and the call belongs in a module that both the server and client entries import. `_currencyStats()` no longer reports `remembered`.
