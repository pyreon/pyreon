New package `@pyreon/command` (Experimental): a command palette. Typo tolerance is not part of v0.

- **Matcher (`@pyreon/command/core`, no dependencies):** `fuzzyMatch`, `rank` and `createRanker`. A subsequence match that is case- and diacritic-insensitive ("resume" finds "Résumé", "strasse" finds "Straße", katakana and hiragana are the same, a Korean syllable is matched by its parts), scored for word starts, camelCase humps, consecutive characters and prefixes (so "np" finds New Project), with the words of a query matching in any order. Match ranges are UTF-16 offsets that are right for surrogate pairs, emoji sequences, flags and combining marks. `createRanker` caches the prepared texts (bounded) and narrows exactly: a query that extends the previous one only looks at what the previous one matched.
- **Registry (`@pyreon/command`):** `createCommands`, `useCommands`, `useCommand`, `provideCommands`. `useCommand` registers a command (or a list, or a function) for the lifetime of a component, so the list matches the screen; titles can be functions (switching the locale re-ranks); the latest registration of an id wins and the earlier one is back when it is removed; recents are bounded and can be persisted. A command's `shortcut` is registered through `@pyreon/hotkeys` once while it is registered and enabled; shortcuts with Ctrl, Alt or Meta fire in a text field, bare keys do not; a development warning names both commands when two share a shortcut.
- **Palette state (`createPalette`):** open and close, the query, nested pages, grouped ranked rows with match ranges, the active row, the ARIA combobox wiring and announcements. Async sources (a function `children`, inside a page or from the root with `inline: true`) are debounced, cancellable and latest-wins, with loading and error states and the previous rows kept while the next load. One palette is open at a time; focus returns to the opener.
- **Components (`@pyreon/command/components`, `@pyreon/command/style.css`):** `<CommandPalette>` and its parts in a native modal `<dialog>`: focus kept in and returned, the page behind inert, scroll locked without a shift, Escape back a page then close, a polite live region, windowed long lists, right to left, close and back buttons for touch, reduced motion.
- **Router (`@pyreon/command/router`):** `routeCommands` makes navigation commands from the route table you gave `createRouter`.
- On the server the registry and the palette are inert.
