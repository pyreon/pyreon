`<OptionChart>` lowers a series' `label`: the `{a}`/`{b}`/`{c}`/`{d}` template resolves at compile time through the web facade's own resolver, so the native chart shows the strings the web shows, and the colour, size and rich styles cross with it. A FUNCTION formatter cannot run at compile time and is named rather than silently dropped.
