# @pyreon/example-native-viz

**PRIVATE / EXPERIMENTAL.** Multiplatform proof: ONE `src/VizApp.tsx` compiles to **web + iOS + Android**, hosting web-only-rich UI surfaces inside native `<WebView>`s with the bidirectional data bridge:

- a **flow pipeline diagram** — `@pyreon/flow/webview`
- a **real CodeMirror 6 code editor** — `@pyreon/code/webview`
- a **real TipTap WYSIWYG** — `@pyreon/rich-text/webview`

Charts are not here: `@pyreon/charts` draws natively on every target (its engine is generated into the Swift and Kotlin runtimes), so it needs no WebView.

- **Forward** — `source` / `doc` signals drive the editors and the graph drives the diagram; on change each surface re-renders in place (no reload).
- **Reverse** — tapping a flow node, or editing an editor, posts back through `pyreonPostMessage` → the native `selected` label.
- The editors use the `<WebView html={HOST} data={…} onMessage={…}>` pattern — the universal path that compiles on every target (the `<CodeWebView>` / `<RichTextWebView>` components are web-side sugar; their bodies can't be PMTC-lowered, but the generated host string + `<WebView>` can). `<FlowWebView>` lowers natively on its own.

`CODE_HOST` / `RICHTEXT_HOST` in `VizApp.tsx` are LOCAL const literals (PMTC inlines a local literal into `PyreonWebView(html:)`), generated by the host builders — regenerate with `bun scripts/gen-hosts.ts`. They load the app-bundled editor globals (`window.CM` / `window.TT`) via `<script src="./assets/{cm,tt}.js">`. CodeMirror 6 and TipTap are modular ESM (no single UMD bundle), so the app bundles its editor and exposes it as a global the host drives — run **`bun scripts/gen-editors.ts`** to produce those (real CodeMirror + TipTap IIFEs, gitignored). A shipping native app inlines the bundle instead — `buildCodeHostHtml({ codemirrorScript })` / `buildRichTextHostHtml({ tiptapScript })` — for an offline, App-Store-safe page.

## Build

```
bun run gen-editors    # produce assets/{cm,tt}.js (real CodeMirror + TipTap bundles) — for running the app
bun run gen-hosts      # regenerate the embedded host literals
bun run build          # → generated/{swift,kotlin}/VizApp.{swift,kt}
```

PMTC emit (the flow + code + rich-text surfaces, **0 warnings, both targets**) is covered by `@pyreon/native-compiler` tests; the host bridges are proven end-to-end against REAL CodeMirror / TipTap in each package's `webview.browser.test` suite.
